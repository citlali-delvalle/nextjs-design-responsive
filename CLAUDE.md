## Commands

- `npm run dev` — start the dev server at http://localhost:3000 (also regenerates the block in `AGENTS.md`)
- `npm run build` — production build; also the way to type-check the project (`tsconfig` has `noEmit`)
- `npm run lint` — ESLint (flat config with `eslint-config-next` core-web-vitals + typescript rules)

There is no test runner configured yet.

## Stack

- Next.js 16.3 (App Router, `app/` directory), React 19.2, TypeScript (strict)
- Tailwind CSS v4 via `@tailwindcss/postcss` — no `tailwind.config.*` file. Theme tokens live in `app/globals.css` under `@theme inline`, mapped from CSS variables on `:root` (e.g. `--background` → `bg-background`, `--foreground` → `text-foreground`). The site is light-only (`color-scheme: light`, no dark token overrides).
- Fonts: Geist and Geist Mono loaded via `next/font/google` in `app/layout.tsx`, exposed as `--font-geist-sans` / `--font-geist-mono` and mapped to Tailwind's `font-sans` / `font-mono`.
- Path alias `@/*` resolves to the repo root.
- `LayoutProps<"/">` / `PageProps` are global, route-typed helpers generated by Next (see `.next/types`); use them instead of hand-written prop types for layouts and pages.

## Project state

`app/page.tsx` is an Apple.com-style photography portfolio (floating glass nav, hero, feature tile, 2-column grid of rounded photo cards with glass captions, about, contact). Project data is a typed array at the top of the file; photos are statically imported from `public/portfolio/` so `next/image` gets intrinsic sizes and `placeholder="blur"` for free.

Design tokens: extend the `:root` variables plus the `@theme inline` block in `app/globals.css` rather than hardcoding colors. Current tokens: `background`, `foreground`, `surface`, `muted`, `accent`, `hairline`, and `font-display` (system SF Pro stack). `.glass` (plus `.glass-pill` for buttons) is the Liquid Glass material; it lives in `@layer components` so Tailwind utilities override it — but its tint is a `background-image`, so a solid-colored glass button needs `bg-none` alongside its `bg-*` color. Parallax is pure CSS too: `.parallax` on the clipping frame plus a `.parallax-layer` wrapper around the media (the layer animates `translate`, so hover `scale-*` on the media still works). The hero is a client component, `components/HeroVideo.tsx` (muted loop, glass play/pause, no autoplay under reduced motion). The `.reveal` class in `globals.css` gives a scroll-driven fade-up (CSS `animation-timeline: view()`, skipped under reduced motion).
